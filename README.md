## 🧥 Project #1 — Virtual Stylist 👗

**Prompt used to build this project:**
> *Build a "Virtual Stylist" app that solves the "I don't know what to wear with this" problem. Let me upload a photo of one specific item (e.g., a difficult-to-match patterned skirt). The AI should analyze its color palette and style, then generate 3 complete, distinct outfit options (Casual, Business, Night Out) featuring that item. It should visualize these as clean "flat-lay" style images so I can see exactly how the pieces work together.)*

### 🧩 Description
The **Virtual Stylist** app helps you decide what to wear by analyzing a clothing item and generating three outfit ideas — one for **Casual**, one for **Business**, and one for **Night Out**.  
AI handles everything from **color analysis** to **outfit visualization** using image-generation tools.

### 🛠️ Tools Used
- **ChatGPT** — for planning and generating the logic
- **DALL·E / Image AI** — to create flat-lay style outfit images
- **HTML/CSS/JS (auto-generated)** — for the front-end interface
